Ctrl-Fit: React Fitness Application

🚀 Overview
Ctrl-Fit is a responsive and interactive fitness application built using React. It allows users to search for exercises, view detailed information, and discover related workout videos. This project was developed by following a comprehensive tutorial by Adrian Hajdin, enhancing my skills in modern web development.

🛠️ Features
Exercise Search: Users can search for exercises based on body parts, equipment, or exercise names.

Detailed Exercise Information: Provides step-by-step instructions, target muscles, and equipment used.

Related Videos: Integrates with YouTube to showcase related workout videos.

Responsive Design: Optimized for various devices, ensuring a seamless user experience.

🧰 Technologies Used
React: Front-end library for building user interfaces.

Material UI: React components for faster and easier web development.

RapidAPI: For fetching exercise and video data.

React Router: Handles routing within the application.

Axios: Promise-based HTTP client for the browser.
